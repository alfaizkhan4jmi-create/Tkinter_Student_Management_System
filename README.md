# Tkinter Student Management System

A simple Python GUI project built using Tkinter and MySQL.

## Features

- Admin Registration
- User Login
- Admin Login
- MySQL Database Connectivity
- Add Student/User Records
- Delete Records
- Display Records using Treeview
- Course Selection using Combobox
- Password Show/Hide
- Background Image

## Technologies Used

- Python
- Tkinter
- MySQL
- PyMySQL
- Pillow
- Treeview

## Files

- firstproject01.py - Main registration page
- userpage.py - User login and profile page
- adminpage.py - Admin login page
